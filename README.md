Instructions:
1. Copy the provided logo and homepage images into `website/assets/`:
   - `logo.jpg` or `logo.png` (primary logo)
   - `logo-footer.jpg` or `logo-footer.png` (small footer logo)
   - `hero.jpg` (hero image shown on the right)
   - `farm.jpg` (why section image)
   - product image: `website/assets/products/ashwagandha.jpg`
2. Place your catalog PDF at `website/assets/Our Product Catalog.pdf`.
3. Install dependencies and run the React app:

```bash
npm install
npm run dev
```

Customization tips:
- Replace contact details in `src/App.jsx`.
- Add more products by expanding the `product` object or converting it to a list.
- Hook the enquiry form to your backend or an email service (e.g., Formspree) for production.
